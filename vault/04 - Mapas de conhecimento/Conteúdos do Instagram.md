## Como usar estas notas

Cada nota contém o estudo completo, o resumo para o caderno e as referências. Use os links para navegar e acrescente suas próprias conexões ao estudar.

Os links dos posts ainda serão preenchidos no campo `instagram` dos arquivos em `conteudos/`. O campo `origem_site` de cada nota indica o artigo correspondente no repositório. Estas são cópias para estudo: alterações posteriores em uma versão não são sincronizadas automaticamente com a outra.

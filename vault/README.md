# Vault Julli doesn't know

Abra a pasta `vault` como um cofre (vault) no Obsidian. Este diretório guarda notas pessoais, fontes, mapas, projetos e templates.

## Estrutura
- `00 - Início`: painel inicial.
- `01 - Caixa de entrada`: captura rápida.
- `02 - Áreas de estudo`: conceitos e notas por área.
- `03 - Fontes`: notas de livros, vídeos, artigos, podcasts e cursos.
- `04 - Mapas de conhecimento`: relações entre temas.
- `05 - Projetos`: experiências e projetos práticos.
- `06 - Publicações`: roteiros e textos aprovados para divulgação.
- `07 - Templates`: modelos de notas.
- `assets`: anexos.

As pastas vazias surgem ao criar a primeira nota ou arquivo nelas. O Git não versiona pastas vazias.

## Segurança e publicação
Este repositório é privado. **Não publique a pasta vault integralmente no GitHub Pages.** O futuro processo de publicação deverá selecionar somente notas com `publicar: true`, depois de revisão explícita. O site atual não lê nem publica esta pasta automaticamente.

## Sincronização
Trabalhe com uma cópia local do repositório, abra a pasta `vault` no Obsidian e sincronize por Git. Evite editar a mesma nota em dois dispositivos sem sincronizar antes e depois. Não inclua tokens ou credenciais no repositório.
